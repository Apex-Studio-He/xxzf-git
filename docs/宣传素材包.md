## 60 秒真机视频分镜

| 时间 | 画面 | 字幕/旁白 |
|---|---|---|
| 0–5 秒 | Android、电脑和 iPhone 放在同一画面 | “同时用几台设备，最烦的就是漏通知。” |
| 5–12 秒 | Android 收到一条专门准备的测试通知 | “Android 来消息时……” |
| 12–22 秒 | Mac 或 Windows 弹出 XXZF 通知 | “电脑能马上提醒，不用反复拿手机。” |
| 22–32 秒 | iPhone 的 Bark 收到同一条测试提醒 | “iPhone 也能通过 Bark 收到。” |
| 32–42 秒 | 放大通知，只显示测试 App 与标题 | “默认只告诉你哪个 App 来了消息，不把原始正文放上大屏。” |
| 42–52 秒 | Android 中打开 App 白名单与设备管理 | “转发哪些 App、连哪些设备，都由自己决定。” |
| 52–60 秒 | GitHub 首页和项目地址 | “完整源码已开源，服务也可以部署在自己的机器上。” |

录制前请使用专门的测试账号和虚构通知；状态栏中的运营商、时间、Wi-Fi 名称和设备名称也要检查。视频发布前至少暂停三次逐帧检查二维码、地址栏和通知画面。

### 正文

同时用 Android、iPhone 和电脑的人，应该都遇到过：工作时一直看着电脑，重要通知却躺在另一台手机里。

所以有了 XXZF——一套开源、自托管的通知转发工具：

- Android 通知可以送到 macOS、Windows 和 iPhone（Bark）
- 默认只显示来源 App 和标题，不把原始正文放上大屏
- 自己选择要监听的 App，也能单独管理接收设备
- 服务地址由自己配置，完整源码公开可检查

它更适合愿意准备域名、HTTPS 和一台长期运行设备的人。项目不提供公共中转服务，也没有“拿来就连别人服务器”的默认配置。

GitHub 搜索：`Apex-Studio-He/xxzf-git`

建议话题：`#开源项目 #安卓 #iPhone #Mac #Windows #效率工具 #自托管`

## B站标题与简介

### 标题

> 我做了一个开源工具，把 Android 通知转发到 iPhone、Mac 和 Windows

### 简介

XXZF 是一套开源、自托管的跨平台通知转发源码。Android 端负责读取用户选中的通知，服务端负责配对和路由，macOS / Windows 原生接收，iPhone 使用 Bark。默认的隐私显示只发送来源 App 和通知标题，不把原始正文作为 Bark 正文发送。

本视频展示真实设备效果、部署条件和源码结构。项目不提供公共中转服务，使用者需要配置自己的 HTTPS 地址并构建客户端。

项目地址：`https://github.com/Apex-Studio-He/xxzf-git`
