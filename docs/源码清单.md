## 为什么不把这些文件放进源码？

下列文件是“运行或发布时生成的数据”，不是缺失的源码：

- APK、DMG、EXE、ZIP 和 SHA-256 成品。
- 已签名的更新 JSON（由 `publish_test_update.py` 从成品和私钥生成）。
- `.env`、数据库、通知归档、诊断、Bark Key、设备凭据和服务日志。
- Android / Apple / Windows 发布证书、私钥和密码文件。

这些内容必须由每个部署者自己生成。把它们发成公共副本反而会让设备互相冲突，或者把用户数据和签名能力暴露给别人。
